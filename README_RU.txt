PEREKUP NATIVE 2.0 — НАТИВНЫЙ ПРОТОТИП НА C++

Это отдельный Android-проект с NativeActivity + C++17 + OpenGL ES 2.0.
Игровой экран и обработка касаний находятся в C++, не в HTML/WebView.
Включены базовые механики: рынок подержанных телефонов (модели примерно 2013–2018), покупка, инвентарь, торг с продавцом, мастерская с ремонтом, банк/кредит, день и расходы, опыт.

КАК СОБРАТЬ НА GITHUB С ТЕЛЕФОНА
1. Распакуй ZIP.
2. Загрузи ВСЕ файлы и папки в новый GitHub-репозиторий (или замени старый проект целиком — не только index.html).
3. Убедись, что workflow находится в .github/workflows/android.yml.
4. Открой Actions → Build native Android APK → Run workflow (или дождись сборки после commit).
5. Скачай артефакт Perekup-Native-debug-APK и установи APK.

ВАЖНО
- Это нативный C++ прототип/основа для дальнейшей разработки, а не автоматическая конвертация прежнего HTML-проекта: прежние приложения и игровые данные не переносятся автоматически.
- Нативная сборка требует Android SDK/NDK и запускается через GitHub Actions. В этом окружении APK не был собран и протестирован на реальном Android-устройстве.
- UI прототипа намеренно простой. Перед выпуском нужно добавить полноценный шрифт кириллицы, сохранения, полноценную совместимость запчастей по моделям, тестирование и более глубокий баланс экономики.
